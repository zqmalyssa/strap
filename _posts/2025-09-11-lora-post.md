lora内容相关

#### 基本概念

lora应该是微软提出来的

就是在训练层中插入一个可训练的

```html

W' = W + B @ A * α / r

```

对于量化的模型可以用qlora

#### 参数设置

如果不设置，一般就是

attention 的 q_proj, k_proj, v_proj, o_proj

或者 MLP 的 gate_proj, up_proj, down_proj

```html

# 可以加入的方式

--lora-layers "q_proj,v_proj"  # 只训练注意力的 Q/V 权重

--lora-layers "all" # 为所有层加上

--lora-layers "0,1,2,10,11" # 指定层号

```

如果指向做“风格注入”、“角色微调”，只需要用到 Q/V

如果想做能力增强（数学、代码），那就是attention的全部

想做大幅SFT，就是再加上MLP层
